## 2024-08-31 - HTTP Parameter Pollution via Starlette dict() cast
**Vulnerability:** HTTP Parameter Pollution (HPP) in `/authorize` and `/token` endpoints caused by silently dropping duplicate parameters when casting `request.query_params` or `request.form()` to a standard Python `dict`.
**Learning:** Starlette's `QueryParams` and `FormData` are `MultiDict` structures. Calling `dict()` on them silently discards all but the last value for duplicate keys. In OAuth endpoints, allowing duplicate parameters like `client_id` or `code_challenge` violates RFC 6749 and can lead to authentication bypass or logic flaws if upstream/downstream components process the first value while the application processes the last.
**Prevention:** Always validate `len(params.multi_items()) == len(params.keys())` before casting a `MultiDict` to a `dict`, and reject the request (400 Bad Request) if duplicates are found, adhering strictly to RFC 6749 requirements.
