## 2025-02-18 - Prevent Content-Security-Policy (CSP) Injection via Malformed Redirect URIs
**Vulnerability:** A Clickjacking vulnerability due to Content-Security-Policy (CSP) injection in the OAuth authorization consent page. The `_form_action_source` function extracted the `netloc` from user-supplied `redirect_uri` parameters using `urllib.parse.urlparse` and interpolated it directly into the `Content-Security-Policy` header's `form-action` directive without adequate sanitization.
**Learning:** Python's `urlparse` tolerates many unusual characters in the `netloc` portion of a URL. If an attacker passes a URL like `https://example.com'; frame-ancestors 'self'`, `urlparse` successfully extracts `example.com'; frame-ancestors 'self'` as the `netloc`. When reflected into a CSP header using string interpolation, the semicolon and single quotes allow the attacker to prematurely close the `form-action` directive and append arbitrary CSP rules, such as overriding `frame-ancestors 'none'` to enable Clickjacking.
**Prevention:** When dynamically constructing CSP headers using components extracted from parsed URLs (e.g., `netloc`), always strictly validate or sanitize the components. Specifically, reject any components containing CSP delimiter characters (like semicolons, single quotes, commas, or spaces) to prevent attackers from escaping the intended directive.
